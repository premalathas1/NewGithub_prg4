# SQL Assignment - Course Table

## Objective

Write SQL statements to perform the following tasks.

1. Create a database named **CollegeDB**.
2. Use the database.
3. Create a table named **Course** with the following fields.

| Column | Data Type |
|---------|-----------|
| CourseID | INT(5) |
| CourseName | VARCHAR(30) |
| Credits | INT |
| DepartmentID | INT(5) |

4. Insert at least **three records** into the Course table.
5. Display the table structure using the **DESCRIBE** command.
